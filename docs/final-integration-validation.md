# 최종 통합 검증 결과

이 문서는 2026년 11월 17일 중간 검증 이후 수행한 최종 통합시험 결과를 정리한다. 이전 Orange Pi 배포와 음성 시험의 상세 기록은 [Orange Pi 음성 연동 검증 기록](orangepi-voice-validation-20261117.md)을 참고한다.

## 1. Orange Pi 음성 시나리오 반복 검증

| 항목 | 내용 |
| --- | --- |
| 실행 환경 | Orange Pi 5 Plus |
| 입력 | 실제 사람 녹음 |
| 시험 범위 | 핵심 음성 시나리오 3종 |
| 반복 횟수 | 시나리오별 10회 |
| 결과 | 총 30회 통과 |

이 결과는 팀 최종 결과보고서와 판넬 최종안에 기록된 내용을 기준으로 한다. 30회 시험의 개별 원시 로그는 서버 저장소에 포함하지 않았다.

## 2. iOS 및 Orange Pi 음성 통합 검증

| 항목 | 내용 |
| --- | --- |
| 시험일 | 2026년 11월 18일 |
| 실행 환경 | iPhone, Expo Go, Orange Pi 5 Plus |
| 결과 | 8개 항목 중 8개 통과 |

확인 범위는 다음과 같다.

- iPhone과 Orange Pi 연결
- 녹음한 WAV 파일의 Voice API 전송
- STT 인식 결과 표시
- Assistant 요청과 결과 조회
- 음성 후속 대화와 일정 처리
- 일정 변경 후 목록과 캘린더 갱신
- 서버 TTS WAV 조회와 자동 재생
- 녹음 및 TTS 임시 파일 정리

프론트엔드 구현과 검증 근거는 [실제 Orange Pi STT/TTS 및 음성 Assistant 연동 커밋](https://github.com/mobile-agent-6/frontend/commit/01b8f307868dfe556544530c9356d05d43068f54)을 참고한다.

## 3. 검증 범위의 제한

- Android 실기기의 실제 STT와 TTS 연동은 시험하지 않았다.
- Web 환경의 실제 음성 기능은 시험하지 않았다.
- 외부 인터넷을 완전히 차단한 내부망 시험은 이번 8개 항목에 포함하지 않았다.
- 2026년 11월 17일 중간 검증 결과와 2026년 11월 18일 최종 iOS 통합 결과는 서로 구분한다.
