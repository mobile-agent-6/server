# Qwen 초기 평가 결과 기록 (v0.1)

이 폴더에는 카테고리 기준을 API와 맞추기 전에 측정한 결과 CSV만 보존한다. 옛 문항 파일, 프롬프트와 실행 코드는 현재 작업 트리에서 제거했다. CSV의 한글 카테고리와 점수는 당시 기준을 설명하는 기록이며 현재 평가셋이나 API 호환성 결과가 아니다.

- `qwen_100_scored_results.csv`: 당시 100문항·정답·모델 응답·개별 판정
- `qwen_100_scored_summary.csv`: 당시 집계

현재 평가 문항과 실행 방법은 [`../../README.md`](../../README.md)를 따른다. 새 기준의 결과를 과거 점수와 직접 비교하지 않는다.
